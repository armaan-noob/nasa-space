Mission Design Quick Start

  1. Select a mission scenario and read the objective.
  2. Pick a launch vehicle, spacecraft, power, comms and trajectory.
  3. Check for red warnings in readiness.
  4. Run the simulation and adjust the design after the debreif.
Design tip: A spacecraft can be reliable and low-mass, but if it cannot return enough data or power its instruments, the mission loses science value.
